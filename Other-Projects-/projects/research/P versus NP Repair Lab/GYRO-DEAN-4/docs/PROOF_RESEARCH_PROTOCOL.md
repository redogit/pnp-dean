# Proof Research Protocol

The project uses a strict proof/evidence separation.

## Promotion states

1. **Conjecture** — quantified statement not proved.
2. **Evidence** — survived stated finite tests; no universal inference permitted.
3. **Lemma** — proved under explicit hypotheses.
4. **Theorem** — proof complete and dependencies closed.
5. **Algorithmic rule** — theorem implemented with reconstruction/certificate contract.

## One-degree experiment

Change one semantic degree when possible: pivot, frame, feature batch, carrier, or repair rule. Record Observation / Change / Remainder.

## Required fields for a new repair

- Input preconditions.
- Exact decision-preservation statement.
- Proof.
- Reconstruction or witness-lifting map.
- Failure behavior.
- Certificate representation.
- Complexity of discovering/applying the repair.
- Interaction with memoization/canonicalization.

## Universal-claim rule

Any claim that would imply polynomial exact solution of all DEAN-4 / Independent-Set instances is treated as P-vs-NP significant. It must not be promoted from experiments, asymptotic intuition, numerical evidence, or a restricted graph family.

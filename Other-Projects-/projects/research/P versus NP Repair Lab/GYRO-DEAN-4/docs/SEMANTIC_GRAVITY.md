# Gyroscopic Semantic Gravity

The canonical state may rotate through equivalent representations. Proven facts are irreversible event-horizon objects; representation choices are reversible.

## Certified mass

For a polynomial-size feature dictionary `M` and exact certified relation system `A y=b`:

`d = |M| - rank(A)`

`M_cert = 2^d`.

A new certified equation batch `B y=c` gains

`g = rank(B N)`

where `N` spans `ker(A)`. If consistent, new mass is at most `M_cert / 2^g`. If inconsistent, mass becomes zero.

## Branch law

Conditioning one unfixed Boolean variable reduces affine dimension by at least one in each nonempty child. Pure branching can therefore conserve mass. Post-branch repair is the source of dissipation.

## Research boundary

A universal theorem that every fully repaired state has a polynomial-cost constant-fraction dissipating action would imply `P=NP`. This package does not claim that theorem has been proved.

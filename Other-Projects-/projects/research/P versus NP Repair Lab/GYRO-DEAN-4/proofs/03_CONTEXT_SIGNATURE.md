# Exact Context Signature and Dominance

Across a cut A|B, a partial independent set X subset A affects the future only through:

`(|X|, N(X) intersect B)`.

If X and Y have equal size and equal blocked-future sets, every future independent Z is compatible with X iff it is compatible with Y.

For existence, if `|X| >= |Y|` and `N(X)∩B subseteq N(Y)∩B`, then X dominates Y: any completion of Y contains enough future vertices to trim to a completion of X.

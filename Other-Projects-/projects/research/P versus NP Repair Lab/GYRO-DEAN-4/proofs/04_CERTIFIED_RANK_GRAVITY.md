# Certified Rank Gravity

Let exact certified relations be `A y=b` over a feature dictionary of size m. Let N span ker(A), so certified nullity is d=m-rank(A).

A new exact relation batch `B y=c` becomes `B N z = c-B y0` after substituting an affine parametrization. If inconsistent, there is no valid solution. Otherwise new nullity is `d-rank(BN)`.

Thus every independent new rank halves the affine hypercube upper bound on remaining binary feature assignments.

# Semantic Jacobian and Block Attacks

Let `W_k` and `h_k` be as in the lifted-MPCA proof. Let `M_i` denote multiplication by x_i on functions over X and let `P_k` project onto W_k. Define

`T_i=(I-P_k) M_i | W_k`

and concatenate `T_k=[T_1 ... T_n]`.

## Theorem 1 — Jacobian rank equals next-degree growth

Every degree-(k+1) monomial is x_i times a degree-k monomial, so

`W_{k+1}=W_k + sum_i M_i W_k`.

Modulo W_k, the generated space is exactly the sum of the images of T_i. Hence

`rank(T_k)=h_{k+1}-h_k`.

## Theorem 2 — Branch exposure equals coordinate Jacobian rank

For fixed i, `W_k + M_i W_k` restricts bijectively to `W_k(X_0) direct-sum W_k(X_1)`: any pair represented by p0,p1 is represented by `p0 + x_i(p1-p0)`. Therefore

`rank(T_i)=h_k(X_0)+h_k(X_1)-h_k(X)=epsilon_{i,k}`.

## Corollary — Guaranteed coordinate exposure

Because the image of the concatenated operator is the sum of coordinate images,

`h_{k+1}-h_k <= sum_i epsilon_{i,k}`.

Thus some coordinate has

`epsilon_{i,k} >= ceil((h_{k+1}-h_k)/n)`.

This is a universal 1/n-share guarantee, not a constant-fraction theorem.

## Block Curvature Theorem

For block B, branch X into all assignments a in `{0,1}^B` and define

`epsilon_{B,k}=sum_a h_k(X_a)-h_k(X)`.

The Boolean branch-indicator polynomials form mutually orthogonal projectors. The algebra generated by multiplication by variables in B splits W_k across the branch restrictions, so its dimension is `sum_a h_k(X_a)`. Since the branch indicators have degree at most |B|,

`0 <= epsilon_{B,k} <= h_{k+|B|}-h_k`.

This makes small-block attack selection a mathematically measurable tradeoff between semantic exposure and `2^|B|` branch cost.
